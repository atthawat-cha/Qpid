ฉันมี โน็ตบุค 1 เครื่อง เป็น windows 

โทรศัพท์ 2 เครื่อง ios / androind

ฉันต้องการสร้าง mobile app เพื่อรองรับทั้ง 2 อย่างนี้

- เป็นแอพที่จะให้ คนที่ผิดหวังในความรักจากการเลือกคู่ที่ผิด มาเริ่มต้นหาคนที่ตรงใจจากแอพนี้ โดยสามารถลงทะเบียนผ่าน social media ต่าง ๆ ได้ และตั้งค่า profile ของตนเพื่อให้คนอื่นรู้จัก และค้นหาคนอื่นๆ ผ่านการกำหนดเงื่อนไขต่าง ๆ เช่น ความต้องการ นิสัย profile ต่าง ๆ หรือ ระยะทาง
- การเลือกคนที่ตรงใจคือ การกดยิงศรไปยังคนนั้น จากนั้นจะมีแจ้งเตือนไปยังคนที่ถูกยิงว่ามีคนตกหลุมรักคุณยิงศรมาหาคุณ ต้องการยิงตอบหรือไม่่
- หากทั้ง 2 ฝ่ายยิงศรใส่กันแล้ว จะต้องผ่านด่านทดสอบใจ คือการตอบคำถามที่อีกฝ่ายสร้างไว้เพื่อใช้เป็น แบบคัดกรองฝ่ายตรงข้ามว่าตรงตามที่ต้องการไหม 
- เมื่อตอบแบบทดสอบเสร็จก็จะมีการให้คะแนนตามคำเฉลยๆ ของฝ่ายตรงข้าม และมีคำแนะนำตามเกณคะแนน เช่นคนนี้ตอบได้ตรงใจคุณ 100 เต็ม คุณจะรับดูใจเขาไหม
- เมื่อกดดูใจ ก็จะเริ่มให้ทั้ง 2 สามารถสนทนากันผ่านแชท แบบ ไม่เก็บข้อมูล และจะหายภายใน 1 วันได้ เพื่อสานความสัมพันต่อไป
